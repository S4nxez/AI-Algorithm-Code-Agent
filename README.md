# AI-Algorithm-Code-Agent
An AI Agent for solving graph-based algorithmic problems through natural-language reasoning, algorithm selection, code generation, validation, execution, and interactive visualization. The agent transforms real-world and abstract problem statements into executable algorithmic solutions, while a dedicated web portal executes the generated code and renders the resulting graph, paths, networks, metrics, and algorithmic states interactively.

## Example

A user can describe a complex optimization problem without specifying the algorithm:

> "A logistics company needs to connect 15 distribution centers. Each possible connection has a different construction cost, and every center must remain connected to the network while keeping the total infrastructure cost as low as possible."

The Agent analyzes the problem, models it as a weighted graph, selects an appropriate algorithm such as **Kruskal or Prim**, and generates the executable code.

The portal then runs the generated code and visualizes the resulting network, selected edges, total cost, and algorithm execution state.
